GUIDE

How it works

Set up your providers once, then turn any text based PDF into a two voice podcast.

IN THIS GUIDE 1. Set up 2. Add a source 3. Create the episode 4. Find your files Privacy & limits Troubleshooting
01

Set up the services

Open Settings and select the text provider that will read your document and write the conversation. POD supports Google Gemini, OpenAI, and Anthropic. Paste the API key for the selected provider, then add an ElevenLabs API key for speech.

You only need one text provider key. You can switch providers later without changing your PDF or output folder.

02

Add a source document

Go to Chat and attach a PDF that contains selectable text. POD extracts up to the first 40,000 characters. Scanned pages and image only PDFs need OCR before the app can read them.

For a better scriptUse a focused document with clear headings. Remove unrelated appendices when the main content is short.
03

Describe the episode

The direction field is optional, but it gives you control over the result. Mention the audience, tone, level of detail, or parts of the document that matter most.

EXAMPLE

Explain this for product managers. Keep it conversational, focus on practical decisions, and end with three takeaways.

Select Create podcast. POD reads the PDF, drafts a two voice script, sends each speaker’s lines to ElevenLabs, and combines the clips into one MP3.

04

Listen and find your files

You can play the finished episode directly in Chat. The Podcasts page keeps a local library of generated episodes and lets you reveal each file on disk.

Every run produces an MP3 and a matching plain text script. Files go to the folder selected in Settings; your Music folder is the default.

Privacy and usage

Stored locally

Your keys are encrypted by the operating system. Episode records, scripts, and audio stay on this computer.

Sent to providers

Document text goes to your chosen text provider. Script lines go to ElevenLabs so it can create the voices.

Provider charges

POD uses your own API accounts. Generation may count toward provider quotas or create charges on those accounts.

Document limit

Only the first 40,000 extracted characters are used to keep requests manageable and predictable.

Troubleshooting

The PDF cannot be read

Open the file and check whether you can select and copy its text. If you cannot, run OCR on the PDF and attach the new version.

Generation stops with an API error

Check that the selected provider matches the key you saved, that the key is active, and that the account has available quota. Save the key again after correcting it.

The episode does not appear in Podcasts

Confirm the output folder still exists and is accessible. The library shows completed episodes recorded by POD and matching MP3/script pairs in the current output folder.

I want a different result

Return to Chat and give more specific direction about audience, tone, length, or priority topics. The original PDF is never modified.
