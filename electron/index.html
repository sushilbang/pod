FIELD GUIDE

How POD works.

Everything you need to turn a PDF into a two voice episode.

01

Connect your services

Open Settings, choose Gemini, OpenAI, or Anthropic, and save that provider’s API key. Add an ElevenLabs key for speech. Keys are encrypted on your computer.

02

Choose an output folder

Set the folder in Settings. POD writes the finished MP3 and a plain text script there. The Music folder is used by default.

03

Start the conversation

In Chat, attach a text based PDF. Add optional direction about tone, audience, or topics, then select Create podcast.

04

Listen and find your files

Follow progress in Chat. When the render finishes, play it there or open Podcasts to revisit the audio and reveal the file on disk.

GOOD TO KNOW

Before you begin

Scanned PDFs need OCR before POD can read them. POD uses the first 40,000 extracted characters to limit API usage.

The selected text provider receives document text to write the script. ElevenLabs receives the script lines to create speech. Their API usage may incur charges.
